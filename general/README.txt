PRESENTACIÓN TIC - CEPRODENT

Archivos:
- index.html
- style.css
- script.js

Uso:
1. Descarga y descomprime el ZIP.
2. Abre index.html directamente con Chrome, Edge o Firefox.
3. Usa las flechas ← → del teclado para cambiar de diapositiva.
4. También funcionan PageUp/PageDown, Home y End.
5. Pulsa F o el botón ⛶ para pantalla completa.
6. En la portada, pulsa "Comenzar presentación".

La presentación contiene 16 diapositivas y las animaciones funcionan con CSS/JavaScript.
No necesita servidor web.

Nota:
El diseño usa Google Fonts mediante CDN. Si se abre sin conexión a Internet, la presentación seguirá funcionando, pero utilizará una fuente alternativa del sistema.
