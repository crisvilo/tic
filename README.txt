PRESENTACIÓN TIC - CEPRODENT

1. Abra index.html en Google Chrome, Microsoft Edge, Firefox u otro navegador moderno.
2. La página inicial conserva el diseño de presentación y permite elegir el programa.
3. "Comenzar recorrido general" abre la presentación original de 16 diapositivas incluida en el material inicial.
4. Cada programa abre una presentación independiente de 16 diapositivas.
5. Use las flechas del teclado ← → para avanzar y retroceder dentro de cada presentación especializada.
